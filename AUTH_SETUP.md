# Настройка авторизации Steam

## Обзор

Система авторизации использует Steam OpenID для аутентификации пользователей. Все исправления внесены для обеспечения корректной работы авторизации.

## Исправленные проблемы

### 1. Исправлен URL для получения пользователя
- **Проблема**: В главной странице использовался абсолютный URL `https://hitmanki.store/api/user`
- **Решение**: Заменен на относительный путь `/api/user`

### 2. Улучшен middleware
- **Проблема**: Неправильная обработка недействительных токенов
- **Решение**: 
  - Добавлена очистка недействительных токенов
  - Улучшена логика проверки публичных маршрутов
  - Добавлен `/api/auth/status` в публичные маршруты

### 3. Улучшена валидация Steam OpenID
- **Проблема**: Неполная валидация OpenID ответов
- **Решение**: 
  - Добавлена проверка `openid.claimed_id`
  - Улучшены регулярные выражения для извлечения Steam ID
  - Добавлено логирование ошибок

### 4. Улучшена обработка ошибок
- **Проблема**: Отсутствие информативных сообщений об ошибках
- **Решение**:
  - Добавлены детальные сообщения об ошибках
  - Добавлено отображение ошибок на главной странице
  - Улучшено логирование ошибок

### 5. Исправлены проблемы с cookies
- **Проблема**: Неправильные настройки безопасности cookies
- **Решение**: 
  - Использование `request.nextUrl.protocol === 'https:'` вместо `process.env.NODE_ENV`
  - Добавлен параметр `path: '/'` для cookies

## Настройка окружения

### Обязательные переменные окружения

```env
# JWT секрет для подписи токенов
JWT_SECRET=your-super-secret-jwt-key-here

# Steam API ключ для получения профилей
STEAM_API_KEY=your-steam-api-key-here

# URL для возврата после авторизации Steam
STEAM_RETURN_URL=http://localhost:3000/api/auth/steam/return

# Базовый URL приложения
NEXTAUTH_URL=http://localhost:3000

# Steam ID администраторов (через запятую)
ADMIN_STEAM_IDS=76561198012345678,76561198087654321
```

### Получение Steam API ключа

1. Перейдите на https://steamcommunity.com/dev/apikey
2. Войдите в свой аккаунт Steam
3. Создайте новый API ключ
4. Добавьте ключ в переменную окружения `STEAM_API_KEY`

## Структура авторизации

### API маршруты

- `GET /api/auth/steam` - Инициация авторизации через Steam
- `GET /api/auth/steam/return` - Обработка возврата от Steam
- `POST /api/auth/logout` - Выход из системы
- `GET /api/auth/status` - Проверка статуса авторизации
- `GET /api/user` - Получение данных пользователя

### Middleware

Middleware проверяет:
- Публичные маршруты (доступны без авторизации)
- Валидность JWT токенов
- Права доступа к административным маршрутам
- Автоматически очищает недействительные токены

### Типы пользователей

- `USER` - Обычный пользователь
- `ADMIN` - Администратор
- `MODERATOR` - Модератор

## Тестирование

### Локальное тестирование

1. Убедитесь, что все переменные окружения настроены
2. Запустите приложение: `npm run dev`
3. Перейдите на http://localhost:3000
4. Нажмите "Login with Steam"
5. Пройдите авторизацию через Steam
6. Проверьте, что вы авторизованы

### Проверка ошибок

Система отображает следующие типы ошибок:
- `invalid_auth` - Неверные данные авторизации Steam
- `invalid_steam_id` - Не удалось получить Steam ID
- `steam_api_error` - Ошибка API Steam
- `database_error` - Ошибка базы данных
- `server_error` - Внутренняя ошибка сервера

## Безопасность

### JWT токены
- Срок действия: 7 дней
- HttpOnly cookies
- Secure в production
- SameSite: lax

### Steam OpenID
- Валидация всех обязательных параметров
- Проверка соответствия identity и claimed_id
- Логирование всех ошибок

### Middleware
- Автоматическая очистка недействительных токенов
- Проверка прав доступа к административным маршрутам
- Защита от несанкционированного доступа

## Мониторинг

### Логирование

Система логирует:
- Ошибки авторизации Steam
- Недействительные токены
- Ошибки базы данных
- Ошибки API Steam

### Отладка
